# Mobile Navigation System for Visually Impaired Users

An Android-based assistive navigation system developed to help visually impaired users perceive obstacles and navigate their surroundings using monocular depth estimation.

The system utilizes **Depth Anything V2** for monocular depth estimation and **NCNN** for optimized on-device inference. The model is converted and deployed for Android using **C++/JNI**, enabling depth estimation directly on a mobile device without relying on cloud-based processing.

The estimated depth information is analyzed to determine obstacle proximity and is communicated to the user through audio feedback. The project focuses on optimizing Depth Anything V2 for mobile hardware while maintaining practical performance for real-time assistive navigation.

## Key Technologies

- Depth Anything V2
- Monocular Depth Estimation
- NCNN
- ONNX
- Android
- C++ / JNI
- Edge AI
- Assistive Technology
